# TinyTale 分类页 & 搜索页 PRD

## 1. 分类页 (Category Page)

### 1.1 功能列表

| 功能 | 描述 |
|------|------|
| 分类列表 | 侧边栏展示所有分类 |
| 筛选 | 类型、年代、地区 |
| 排序 | 最新、最热、评分 |
| 短剧网格 | 分类下的短剧列表 |
| 分页/加载 | 无限滚动或分页 |

### 1.2 页面结构

```
/category              # 分类首页
/category/:slug      # 分类详情
```

---

## 2. 搜索页 (Search Page)

### 2.1 功能列表

| 功能 | 描述 |
|------|------|
| 搜索框 | 关键词输入 |
| 搜索建议 | 实时搜索建议 |
| 热门搜索 | 热门关键词 |
| 搜索结果 | 匹配结果列表 |
| 筛选 | 类型、评分 |
| 无结果 | 空状态提示 |

### 2.2 页面结构

```
/search?q=keyword    # 搜索结果
```

---

## 3. API 接口

### 3.1 分类
```
GET /api/categories
GET /api/dramas?category=:slug
```

### 3.2 搜索
```
?q=GET /api/searchkeyword
```
