### 1.2 功能列表

| 功能 | 描述 |
|------|------|
| 封面海报 | 高清竖屏封面 (9:16) |
| 基本信息 | 标题、评分、分类、年份、集数 |
| 播放按钮 | 立即播放第一集 |
| 收藏按钮 | 收藏/取消收藏 |
| 分享功能 | 复制链接、社交媒体分享 |

### 1.3 交互逻辑

- **点击播放**: 进入播放页，自动播放第一集
- **点击集数**: 进入播放页，播放选中集数
- **未解锁集数**: 点击弹出解锁提示
- **收藏状态**: 实时同步到用户账户

### 2.2 播放器功能

| 功能 | 描述 |

| 条件 | 行为 |

| 播放完毕 | 自动播放下一集 |

## 3. 用户路径

### 3.1 播放免费集数
```
首页 → 点击短剧 → 详情页 → 点击播放 → 播放页
```

### 3.2 解锁付费集数
```
详情页 → 点击付费集数 → 解锁弹窗 → 确认支付 → 播放
```

### 3.3 收藏短剧
```
详情页 → 点击收藏 → 登录/注册 → 收藏成功
```

## 4. API 接口

### 4.1 详情页
```
GET /api/dramas/:id
Response: {
  drama: Drama,
  relatedDramas: Drama[],
  isFavorited: boolean
}
```

### 4.2 播放页
```
GET /api/episodes/:id
Response: {
  episode: Episode,
  videoUrl: string,
  isUnlocked: boolean,
  nextEpisode: Episode | null,
  prevEpisode: Episode | null
}
```

### 4.3 解锁剧集
```
POST /api/coins/unlock
Body: { episodeId: string }
Response: { success: boolean, newBalance: number }
```

### 4.4 收藏
```
POST /api/user/favorites
Body: { dramaId: string }
Response: { success: boolean }
```
