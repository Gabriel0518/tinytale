# TinyTale UI/UX 设计文档

## 1. 设计原则

### 1.1 视觉风格
- **主题**: 深色模式 (Netflix/Disney+ 风格)
- **主色调**: 黑色背景 (#141414)
- **强调色**: 红色 (#E50914) 或 金色 (#FFD700)
- **文字色**: 白色 (#FFFFFF) / 灰色 (#B3B3B3)

### 1.2 响应式断点
| 设备 | 宽度 |
|------|------|
| Mobile | 375px |
| Tablet | 768px |
| Desktop | 1440px |

---

## 2. 页面设计

### 2.1 首页 (Home Page)

#### 顶部导航栏
- 左侧: Logo + 导航链接
- 中间: 搜索框
- 右侧: 分类按钮 + 用户头像

#### 横幅轮播
- 宽度: 100%
- 高度: 60vh (Mobile) / 80vh (Desktop)
- 自动轮播: 5秒
- 指示器: 底部圆点

#### 短剧卡片
```
┌─────────────────┐
│  [Cover Image]  │
│  ┌───────────┐  │
│  │  PLAY    │  │
│  └───────────┘  │
│  Title          │
│  ★ 4.5 • 20集  │
└─────────────────┘
```
- 圆角: 8px
- 阴影: 0 4px 12px rgba(0,0,0,0.3)
- Hover: 放大1.05倍

#### 分类区域
- 横向滚动
- 标签式筛选

```
├─────────────────────────────────┤
```
```
│                                 │

│  [1.0x]     [🔊]     [集列表]  │
└─────────────────────────────────┘
```

#### 控件
- 自动隐藏: 3秒无操作
- 进度条: 底部红色进度
- 倍速: 0.5x / 0.75x / 1x / 1.25x / 1.5x / 2x
- 选集: 右侧滑出面板

#### 未解锁状态

```
│      [Video Preview]            │
```

## 3. 组件库

### 3.1 基础组件

| 组件 | 用途 |
|------|------|
| Button | 按钮 (Primary/Secondary/Ghost) |
| Input | 输入框 |
| Card | 卡片容器 |
| Modal | 弹窗 |
| Toast | 提示消息 |
| Loading | 加载状态 |
| Badge | 徽章 |

### 3.2 业务组件

| 组件 | 用途 |
|------|------|
| DramaCard | 短剧卡片 |
| EpisodeItem | 剧集项 |
| VideoPlayer | 播放器 |
| CoinBalance | 金币余额 |
| PaymentModal | 支付弹窗 |

## 4. 颜色系统

### 主色
```css
--color-bg-primary: #141414;
--color-bg-secondary: #1f1f1f;
--color-bg-elevated: #2a2a2a;
```

### 强调色
```css
--color-primary: #E50914;    /* Netflix Red */
--color-gold: #FFD700;       /* Gold */
--color-success: #46d369;
--color-warning: #ffa00a;
--color-error: #e50914;
```

### 文字色
```css
--color-text-primary: #FFFFFF;
--color-text-secondary: #B3B3B3;
--color-text-tertiary: #808080;
```
