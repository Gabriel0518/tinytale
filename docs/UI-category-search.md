# TinyTale 分类页 & 搜索页 UI 设计

## 1. 分类页布局

```
┌────────┬─────────────────────────────────┐
│        │  Category Name                  │
│ CATEG  │  [Filter] [Sort ▼]             │
│        │                                 │
│ Romance│  ┌────┐ ┌────┐ ┌────┐         │
│ Drama  │  │    │ │    │ │    │         │
│ Comedy │  │Card│ │Card│ │Card│         │
│ Mystery│  │    │ │    │ │    │         │
│ ...    │  └────┘ └────┘ └────┘         │
│        │                                 │
└────────┴─────────────────────────────────┘
```

## 2. 搜索页布局

```
┌─────────────────────────────────┐
│  [Search Input]              🔍 │
├─────────────────────────────────┤
│  Hot Searches                  │
│  [Tag] [Tag] [Tag]            │
├─────────────────────────────────┤
│  Results (20)                  │
│  ┌────┐ ┌────┐ ┌────┐         │
│  │Card│ │Card│ │Card│         │
│  └────┘ └────┘ └────┘         │
└─────────────────────────────────┘
```

## 3. 样式细节

- 分类侧边栏: 200px宽
- 搜索框: 圆角-full, 深色背景
- 筛选标签: 可选中/未选中状态
- 短剧网格: 同首页布局
