# TinyTale 后台管理系统 - 剧集管理 PRD

## 1. 功能列表

| 功能 | 描述 |
|------|------|
| 剧集列表 | 分页展示所有短剧 |
| 创建剧集 | 添加新短剧 |
| 编辑剧集 | 修改短剧信息 |
| 删除剧集 | 删除短剧 |
| 剧集管理 | 集数CRUD |
| 分类管理 | 分类CRUD |
| 上传 | 封面上传 |

---

## 2. 页面结构

```
/admin              # Dashboard
/admin/dramas      # 剧集列表
/admin/dramas/new  # 创建剧集
/admin/dramas/:id  # 编辑剧集
/admin/categories  # 分类管理
```
