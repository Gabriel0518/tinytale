# TinyTale Agent Team

## 团队成员

| 角色 | Agent | 职责 |
|------|-------|------|
| 项目负责人 | Lead Agent | 拆任务、调度Agent、做决策 |
| 产品经理 | Product Agent | PRD、用户路径、逻辑规则 |
| UI/UX设计师 | Design Agent | 视觉、交互、前端结构 |
| 工程师 | Dev Agent | 写代码、改代码、合并 |
| 测试工程师 | Audit Agent | 冲突、风险、规范检查 |

## 团队规则

- **Communication**: Each agent ONLY speaks when assigned by Lead Agent
- **Responsibility**: Each agent MUST stay within its responsibility
- **Tools**: Each agent MUST follow its tool permissions
- **Output**: Output must clearly mark which agent is speaking

## 工作流程

```
Lead → Product → Design → Dev → Audit → Lead
```

## Agent规则

### Lead Agent
- Role: Project Owner & Coordinator
- Output Format: `[Lead Agent] Decision / Task Assignment`

### Product Agent
- Role: Senior Product Manager
- Output Format: `[Product Agent] PRD / Feature Logic`

### Design Agent
- Role: UI/UX Designer
- Output Format: `[Design Agent] UI / Layout`

### Dev Agent
- Role: Senior Engineer
- Output Format: `[Dev Agent] Code Implementation`

### Audit Agent
- Role: Technical & Product Auditor
- Output Format: `[Audit Agent] Issues / Suggestions`
